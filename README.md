# Python Edu

Небольшой учебный репозиторий с примерами базовых и продвинутых возможностей Python. Каждый файл можно запускать отдельно и использовать как краткий практический конспект.

## Что изучается

- встроенные типы, функции и ключевые слова Python;
- анонимные функции `lambda`;
- протокол итераторов: `__iter__()` и `__next__()`;
- генераторы и оператор `yield`;
- свойства класса: `@property`, setter и deleter;
- ограничение атрибутов класса через `__slots__`;
- создание классов с пользовательским метаклассом.

## Структура проекта

| Файл | Описание |
| --- | --- |
| `all_keywords.py` | Примеры типов данных, встроенных функций и ключевых конструкций языка |
| `lambda.py` | Пример анонимной функции |
| `iterator.py` | Реализация собственного итератора |
| `generator.py` | Итерируемый объект с протоколом `__iter__` / `__next__` |
| `ex_yeild.py` | Простой генератор с `yield` |
| `decor_property.py` | Getter, setter и deleter с декоратором `@property` |
| `ex_slot.py` | Ограничение набора атрибутов через `__slots__` |
| `meta_class.py` | Добавление атрибута класса с помощью метакласса |
| `prep/all_keywords.py` | Расширенный практический пример с записью вывода в файл |
| `prep/example.txt` | Пример результата выполнения подготовительного скрипта |

## Требования

- Python 3.10 или новее (в примерах используется конструкция `match` / `case`);
- сторонние библиотеки не требуются.

## Запуск

Клонируйте репозиторий и перейдите в его каталог:

```bash
git clone https://github.com/nas-kz/Pyton-Edu.git
cd Pyton-Edu
```

Запустите нужный пример:

```bash
python iterator.py
python ex_yeild.py
python decor_property.py
```

Для Windows также можно использовать команду `py`:

```powershell
py meta_class.py
```

## Как работать с примерами

1. Откройте выбранный файл и прочитайте комментарии.
2. Перед запуском попробуйте предсказать результат.
3. Запустите файл из терминала.
4. Измените входные значения или дополните пример своим кодом.
